## Тема

Асинхронный JavaScript и REST API. Приложение «Доска публикаций».

## Возможности

- загрузка пяти публикаций методом GET;
- использование `fetch`, `async/await` и JSON;
- проверка `response.ok` и обработка HTTP-ошибок;
- создание публикации методом POST;
- проверка заголовка и текста после `trim()`;
- состояния загрузки и отправки с блокировкой кнопок;
- обработка сетевых ошибок и тайм-аута через `try/catch/finally`;
- динамическое обновление DOM без перезагрузки страницы;
- безопасный вывод данных через `textContent`;
- адаптивный интерфейс для компьютера и телефона.

## Запуск

Подключение к интернету необходимо для обращения к JSONPlaceholder.

### Вариант 1

Откройте файл `index.html` в современном браузере.

### Вариант 2

Запустите локальный сервер из каталога проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Используемые API

- GET: `https://jsonplaceholder.typicode.com/posts?_limit=5`
- POST: `https://jsonplaceholder.typicode.com/posts`

JSONPlaceholder имитирует создание публикаций. Новая запись возвращается в ответе, но постоянно на сервере не сохраняется.

## Результаты проверки

| Проверка | Результат |
| --- | --- |
| GET пяти публикаций | Получены и отображены 5 записей |
| Пустая форма и строки из пробелов | Показано сообщение, запрос не отправлен |
| Корректная POST-форма | Получен успешный ответ и ID созданной записи |
| HTTP 404 | Показана понятная ошибка, кнопка снова доступна |
| Сетевой сбой или тайм-аут | Ошибка обработана, интерфейс разблокирован |
